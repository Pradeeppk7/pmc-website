GitHub From First Commit to Live Site

Go from a copy of a project to a website anyone can visit. You’ll create a branch, make and push a change, merge it, and publish the result with GitHub Pages.

  3. 03 Commit and push your work

  5. 05 Publish your site with GitHub Pages
